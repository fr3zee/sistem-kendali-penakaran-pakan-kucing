# finalisasi

## Tujuan
Generate narasi, gambar, dan DOCX Bab IV dari output pipeline sebelumnya.

## Input
Output dari `hasil/analisis_inferensial/` dan `hasil/sintesis_hasil/`

## Skrip Utama
1. `tahap5_generate_narasi_bab4.py` — narasi_bab4.md
2. `tahap5_visualisasi_bab4.py` — gambar kurva respons
3. `tahap5_generate_docx_bab4_revisi_terbatas.py` — DOCX Bab IV (kanonis)

## Output
`hasil/finalisasi/`

## Cara Menjalankan
```
python code/finalisasi/tahap5_generate_narasi_bab4.py
python code/finalisasi/tahap5_visualisasi_bab4.py
python code/finalisasi/tahap5_generate_docx_bab4_revisi_terbatas.py
```

## Hubungan dengan Skripsi
Dokumen final Bab IV.
