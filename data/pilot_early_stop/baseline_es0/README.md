# baseline_es0

Data baseline tanpa early stop (ES = 0 g). Digunakan sebagai referensi metodologis.

## Isi
- `Dokumen_Analisis_Baseline_Early_Stop_0g_NETRAL.docx` — agregat 140 trial valid (SP 10-30 g)
- `raw_log_partial/` — 5 log GS PID ES=0 (SP 10/15/20/25/30); hanya sebagian log tersedia

## Catatan
Folder ini hanya memuat sebagian log baseline ES 0 g. Hasil agregat 140 trial bersumber dari dokumen
analisis baseline dan tidak seluruhnya dapat direkonstruksi dari log individual yang tersedia.

ES 0 g tidak dimasukkan ke perbandingan kandidat ES 0.2-0.4 g karena:
- jumlah trial tidak seimbang antar SP
- cakupan setpoint berbeda (SP10 tidak dipakai pada pengujian final)
- berasal dari rangkaian pengujian terpisah
