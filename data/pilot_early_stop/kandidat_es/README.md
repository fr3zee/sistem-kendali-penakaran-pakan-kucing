# kandidat_es

Data uji pilot kandidat early stop: ES 0.2 g, 0.3 g, 0.4 g.

## Isi
- `pilot_ES_master.csv` — 74 trial valid (Fixed PID + GS PID, 3 nilai ES, SP 15-30)
- `pilot_ES_summary_balanced_3trial.csv` — ringkasan balanced (3 trial per kombinasi)
- `pilot_ES_summary_all_valid.csv` — ringkasan semua trial valid
- `pilot_ES_QC_report.md` — laporan QC
- `pilot_ES_rekomendasi.md` — rekomendasi penetapan ES 0.4 g

Raw log kandidat ES 0,2–0,4 g tidak disertakan dalam repositori publik. CSV master, ringkasan, laporan QC, dan rekomendasi dipertahankan sebagai artefak hasil pilot.

## Keputusan
ES 0.4 g dipilih sebagai konfigurasi bersama. Lihat `pilot_ES_rekomendasi.md`.
